# Programación A – ILERNA DAM

Este repositorio contiene los ejercicios, actividades prácticas y apuntes correspondientes a la asignatura **Programación A**, del ciclo formativo de Grado Superior en Desarrollo de Aplicaciones Multiplataforma (DAM) de ILERNA.

El objetivo es practicar los fundamentos de la programación, desarrollar habilidades de resolución de problemas y documentar mi progreso durante el aprendizaje de Java.


## Contenidos

- Pseudocódigo y algoritmos.
- Variables y tipos de datos.
- Operadores aritméticos y lógicos.
- Estructuras condicionales.
- Bucles e iteraciones.
- Métodos y funciones.
- Programación orientada a objetos (POO).
- Fundamentos de Java.

*Los contenidos se irán ampliando conforme avance en la asignatura.*

## Tecnologías y herramientas

- Java
- Git
- GitHub

## Objetivo del repositorio

Este repositorio tiene una finalidad educativa y personal. Su propósito es mantener organizados los ejercicios del cuadernillo, documentar los conocimientos adquiridos y llevar un seguimiento de mi evolución como programador.
